# 数据更新与来源

**更新时间：2026-08-09**

## 当前 MVP 链路

```text
AKShare
-> FastAPI Provider Adapter
-> 标准化 Fund Record
-> 硬约束筛选 + 大模型研究 API
-> Vue 页面
```

`REFERENCE` 模式设置 `FUND_COMPASS_AKSHARE_ENABLED=true` 后，服务端调用 AKShare 的：

- `fund_name_em()`：全市场基金目录；
- `fund_open_fund_rank_em(symbol="全部")`：开放式基金排行、单位净值、累计净值、日期和区间收益；
- `fund_open_fund_info_em()`：单基金历史净值序列；
- 后续接入 `fund_etf_spot_em()`：ETF 场内行情参考。

AKShare DataFrame 不直接进入业务层。适配器应校验列名、类型、日期和净值，记录 `sourceType=AKSHARE_PUBLIC`、`trustLevel=LOW`、抓取时间和解析器版本。当前 Reference 数据只用于研究验证，不自动宣称官方或授权数据。

## 数据字段边界

| 字段 | 当前来源 | 状态 | 使用边界 |
|---|---|---|---|
| 基金代码、名称、类型 | AKShare 目录/排行 | Reference | 显示公开聚合来源。 |
| 单位净值、累计净值、日期 | AKShare 排行、单基金历史接口 | Reference | 普通基金正式 NAV 为日频，不称盘中实时。 |
| 近 1/3/6/12 月收益 | AKShare 排行、历史 NAV 计算 | Reference | 历史指标绑定 NAV 序列和计算版本。 |
| 波动率、最大回撤、夏普 | 单基金 AKShare 历史 NAV + Python 指标函数 | 按需计算 | 历史样本不足时明确标记，不用预置值填充。 |
| ETF 场内价格、涨跌幅 | AKShare `fund_etf_spot_em()` | Reference | 不等于正式 NAV，不参与普通基金推荐排序。 |
| ETF IOPV | 未接入 | 未实现 | 必须独立字段，不与 marketPrice 混淆。 |
| 费率、规模、经理、申赎状态 | AKShare 排行部分字段 | 不完整 | 未获得时显示“未获取”，不使用模拟值；后续需主数据和公告适配器补齐。 |

## 生产边界

AKShare、公开聚合接口和网页行情只能作为开发/参考入口。公开服务或商业化前必须确认自动访问、批量缓存、再分发、来源署名、限流和商业使用许可；正式环境应替换为已授权数据源或官方披露适配器。
